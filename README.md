# Analiza-danych-w-R-projket-
Studencki projekt zespołowy Analiza danych w R 2025/2026. Członkowie zespołu: Zuzanna Jachna, Zuzanna Miechowicz, Wiktoria Dobosz, Patryk Piotrowski
## Cel projektu
Celem tego projektu jest określenie, jakie zmienne mają największy wpływ na cenę za noc w hotelach resortowych i miejskich, jak lokalizacja wpływa na popularność obu typów obiektów, a także w jakich okresach rezerwacje występują najczęściej.
